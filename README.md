

# AmmChini AI: Bangladeshi Mango Variety Classification

A computer vision project designed to identify and classify different varieties of Bangladeshi mangoes in real-time using lightweight Convolutional Neural Networks (CNNs).

## 🚀 Overview

**AmmChini AI** addresses the challenge of accurately identifying mango varieties, which is essential for agricultural management, quality control, and supply chain efficiency. This project leverages the **MobileNet** architecture to achieve high-accuracy, real-time image classification, specifically optimized for deployment on resource-constrained devices.

## 🛠 Technical Stack

* **Core Architecture:** MobileNet (optimized for low latency and high performance).
* **Frameworks:** TensorFlow / Keras.
* **Dataset:** Curated collection of localized Bangladeshi mango varieties.
* **Evaluation Metrics:** Precision, Recall, F1-Score, and Confusion Matrix analysis.

## 🔑 Key Features

* **Lightweight Model:** Built upon MobileNet, ensuring fast inference speeds without sacrificing classification accuracy.
* **Real-time Inference:** Capable of processing image inputs for immediate variety detection.
* **Localized Focus:** Specifically trained on features characteristic of mangoes found in Bangladesh, ensuring practical applicability.

## 📊 Methodology

1. **Data Acquisition:** Collection and preprocessing of images representing various mango species.
2. **Model Training:** Fine-tuning the MobileNet architecture to handle localized features.
3. **Benchmarking:** Comparison analysis to ensure optimal performance (MobileNetV2 vs. V3).
4. **Performance Visualization:** Generation of confusion matrices to evaluate classification success across specific classes.
